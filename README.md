# 📊 Engineering Data Analysis

A Python-based engineering data analysis project using experimental temperature measurements.

## 📌 About the Project

This project analyzes temperature measurements collected over time.

The goal is to practice data analysis techniques commonly used in engineering, including statistical analysis, calculation of temperature variation, heating rates, and data visualization.

## 📊 Analysis

The program performs:

- Data loading from a CSV file
- Descriptive statistical analysis
- Temperature variation calculation
- Standard deviation calculation
- Average heating rate calculation
- Heating rate calculation for each time interval
- Temperature vs. time visualization
- Heating rate vs. time visualization

## ▶️ How to Run

Make sure Python is installed.

Install the required libraries:

    pip install pandas matplotlib

Run the program:

    python main.py

The program will analyze the measurements and generate the plots automatically.

## 📈 Results

The analysis includes statistical information about the temperature measurements and shows how the temperature and heating rate change over time.
